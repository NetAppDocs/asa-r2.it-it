= Invio e visualizzazione dei casi di supporto per i sistemi storage ASA R2
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Se riscontri un problema che richiede assistenza, usa ONTAP System Manager per inviare un caso al supporto tecnico o per visualizzare i casi chiusi o in corso.

Devi essere link:https://docs.netapp.com/us-en/active-iq/task_login_activeiq.html["Registrato con Active IQ"^] per visualizzare i casi di supporto per il tuo sistema ASA r2.

.Fasi
. Per inviare una richiesta di supporto, in System Manager, seleziona *Cluster > Supporto*; poi seleziona *Vai a NetApp Support*.
. Per visualizzare un caso precedentemente inviato, in System Manager, seleziona *Cluster > Support*; poi seleziona *View my cases*.
