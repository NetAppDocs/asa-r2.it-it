= Disabilita la protezione ransomware autonoma predefinita sui sistemi storage ASA r2
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Quando inizializzi un nuovo cluster ASA ONTAP 9.18.1 r2 o aggiorni un cluster a ONTAP 9.18.1, ARP/AI viene abilitato per impostazione predefinita su tutte le nuove unità di storage dopo un grace period di 12 ore. Se non disabiliti ARP/AI durante quel periodo, ONTAP lo abilita a livello di cluster per le nuove unità di storage quando il grace period termina.

Le unità di archiviazione create in ONTAP 9.17.1 devono essere link:enable-anti-ransomware-protection.html["abilitato manualmente"] per ARP/AI.

.Fasi
È possibile disattivare l'abilitazione predefinita durante o dopo il grace period iniziale di 12 ore.

[role="tabbed-block"]
====
.System Manager
--
. Selezionare *Cluster > Settings* (cluster > Impostazioni).
. Disabilita ARP:
+
** Per disattivare durante il grace period di 12 ore:
+
... Nella sezione *Anti-ransomware*, seleziona *Non abilitare* e poi seleziona *Disabilita*.


** Per disattivare dopo il grace period di 12 ore:
+
... In *Anti-ransomware*, seleziona image:icon_pencil.gif["Modifica"] e poi deseleziona *Abilita per nuove unità di archiviazione*.
... Seleziona *Save*






--
.CLI
--
. Verificare lo stato di abilitazione predefinito:
+
[source, cli]
----
security anti-ransomware auto-enable show
----
. Disabilita l'attivazione predefinita per le unità di storage esistenti e nuove:
+
[source, cli]
----
security anti-ransomware auto-enable modify -default-existing-volume-state false -default-new-volume-state false
----
