= Verifica della connettività host sul sistema di storage ASA R2
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
In caso di problemi con le operazioni dei dati host, è possibile utilizzare Gestione sistema di ONTAP per verificare che la connessione dall'host al sistema di storage ASA R2 sia attiva.

.Fasi
. In System Manager, selezionare *host*.
+
System Manager visualizza lo stato della connettività host accanto al nome del gruppo host:

+
** *OK*: Indica che tutti gli iniziatori sono connessi a entrambi i nodi.
** *Parzialmente connesso*: indica che alcuni degli initiator non sono connessi a entrambi i nodi.
** *Nessuno collegato*: Indica che non sono collegati iniziatori.




.Quali sono le prossime novità?
Aggiorna il tuo host per correggere i problemi di connettività. ONTAP ricontrollerà lo stato della connessione ogni 15 minuti.
