= Ottimizza la sicurezza e le prestazioni del cluster con ASA r2 System Insights
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Visualizza _Insights_ in Gestione di sistema di ONTAP per identificare le Best practice e le modifiche alla configurazione che puoi implementare sul tuo sistema ASA R2 per ottimizzare la sicurezza e le performance del cluster.

Ad esempio, supponi di avere server Network Time Protocol (NTP) configurati per il tuo cluster. Tuttavia, non sai di avere meno server NTP rispetto al numero raccomandato necessario per una gestione ottimale dell'ora del cluster. Per aiutarti a prevenire problemi che possono verificarsi quando l'ora del cluster non è accurata, Insights ti avvisa che hai troppo pochi server NTP configurati e ti offre opzioni per saperne di più sul problema, risolverlo o ignorarlo.

image:insights.png["schermata della pagina delle informazioni di system manager"]

.Fasi
. In System Manager, selezionare *Insights*.
. Rivedere i consigli.


.Cosa succederà
Eseguire le azioni necessarie per implementare le Best practice e ottimizzare la sicurezza e le performance del cluster.
